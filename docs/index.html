拡張的数譜

概要

数譜とは素数大富豪における試合の記録を行うための記法である 2018年にカステラ氏によって提案された「標準的数譜」をベースに，可読性を担保しつつプログラム等で処理しやすいフォーマットに成形した「拡張的数譜」を提案する

編集履歴

  • v0.0.1: 初版作成

フォーマット

  • 初期手札
    {プレイヤー名}:{初期手札}
  • 初期手札以外
    {プレイヤー名}:{革命状態},{ドロー},{行動}{特殊}{上がり},{ペナルティ}

共通の表記ルール

  • プレイヤーの行動を1ターンと定義し，1ターンにつき1行で記載する
  • 各カードの表記は以下のとおりとする
    • エース(1): A
    • 2〜9: 2 〜 9 (アラビア数字)
    • 10: T
    • ジャック(11): J
    • クイーン(12): Q
    • キング(13): K
    • ジョーカー: X

フォーマットの詳細

{プレイヤー名}

  • プレイヤーを識別する文字列
  • 区切り文字の判別を行うため，, や : は使用してはならない

表記ルール

  • , および : 以外の1文字以上

{初期手札}

  • 初期手札を示す文字列
  • 初期手札のカードを丸括弧で囲む

表記ルール

  • S({初期手札のカード}) が1回
  • {初期手札のカード} は A23456789TJQKX の中から1文字以上

{革命状態}

  • 革命状態を示す文字列
  • 革命状態である場合は，プレイヤーの区切り文字（:）の直後に [R] を記載する

表記ルール

  • {革命状態} は 0回または1回
  • {革命状態} の内容は [R]

{ドロー}

  • プレイヤーがカードをドローしたときに示す文字列
  • ドローしたカードを丸括弧で囲む

表記ルール

  • D({ドローしたカード}) が0回または1回
    • {ドローしたカード} は A23456789TJQKX の中から1文字

M({行動})

  • プレイヤーの行動を示す文字列
  • 行動内容を括弧で囲む パスの場合は % を使用する

表記ルール

  • M({行動内容}) が0回または1回
  • {行動内容} は以下のいずれか
  1. {場に出したカード}(={素因数場に出したカード})(|X={ジョーカーの代わりの数}...)
    • {場に出したカード} は A23456789TJQKX の中から1文字以上
    • {素因数場に出したカード} は素因数場用文字 A23456789TJQKX*^ の中から1文字以上
      • 素因数場にカードが出た場合，{場に出したカード} の後ろに = を付け，その後に {素因数場に出したカード} を記載する
    • {ジョーカーの代わりの数} は 0A23456789TJQKX の中から1文字
      • {場に出したカード} または {素因数場に出したカード} の中に X が含まれていた場合，後ろに |X= を付け，その後に {ジョーカーの代わりの数} を記載する
      • {ジョーカーの代わりの数} は，A が 1，T が 10，J が 11，Q が 12，K が 13 を表す
      • ジョーカーが2枚以上ある場合は，|X={ジョーカーの代わりの数}|X={ジョーカーの代わりの数} のように続けて記載する このとき，{場に出したカード} および {素因数場に出したカード} に含まれる X の順序と一致させること
  2. % （1文字）

{特殊}

  • {場に出したカード} の内容に応じて記載する文字列
  • 四角括弧で内容を囲んで表記する

表記ルール

  • [GC]，[RR]，または [IN] が0回または1回
    • [GC] は {場に出したカード} の数値が 57 のときに記載する
    • [RR] は {場に出したカード} の数値が 1729 のときに記載する
    • [IN] は {場に出したカード} が X 1文字のときに記載する

{上がり}

  • あがり（ゲーム終了）を示す文字列
  • # を記載する

表記ルール

  • # が0回または1回

{ペナルティ}

  • プレイヤーがペナルティを受ける際に示す文字列
  • ペナルティの内容を丸括弧で囲む
  • 山札がないためにカードを引けない場合においても記載する（ペナルティのカードがない場合は P() と記載する）

表記ルール

  • P({ペナルティを受けるカード}) が0回または1回
  • {ペナルティを受けるカード} は A23456789TJQKX の中から0文字以上
